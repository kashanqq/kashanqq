## 🚗 Main project

### [The Last Car](https://github.com/kashanqq/TheLastCar)

A co-op winter survival-driving game in Unreal Engine 5. One car, a frozen mountain road, and a crew that has to keep it running.

- **Car assembly:** about 15 detachable parts with ghost previews, driven by data tables
- **Driving:** Chaos Wheeled Vehicle physics with custom torque curves and async physics
- **Survival:** fuel, body temperature and stamina
- **Inventory:** grid-based trunk storage and a single-key interaction system
- **Map:** built on real heightmap data of Lofoten, Norway

The game is developed privately. The repo is a public window into it: devlogs and selected Blueprint graphs.
